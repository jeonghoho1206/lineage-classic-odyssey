# LINEAGE CLASSIC ODYSSEY — V3.4 Final Candidate Reviewed 3

리니지 클래식 전용 정적 의사결정 도구입니다.

## 이번 검수 기준
- 일반 사용자가 홈에서 핵심 계산기를 바로 찾을 수 있는지
- 장비 비교 / 오늘의 결정 / 사냥 효율 / 성장·강화 / 연구소 / 근거 / 업데이트 / 공식 사전 / 결과 공유가 실제로 동작하는지
- 숫자 입력 범위와 잘못된 입력을 BLOCK하는지
- 계산 결과가 공식 게임 공식처럼 오해되지 않는지
- 공유 데이터에 캐릭터 이름이 포함되지 않는지
- ZIP에서 압축 해제 후 `index.html`을 열었을 때 외부 JS 파일 의존성 때문에 화면이 깨지지 않는지
- 모바일 화면에서 1열로 자연스럽게 전환되는지

## 사용법
1. ZIP을 먼저 압축 해제합니다.
2. `index.html`을 엽니다.
3. 홈의 `⚡ 바로 계산`에서 원하는 계산기를 선택합니다.
4. 실제 관측값을 입력하고 계산합니다.

## 주의
- 이 사이트는 NC의 공식 서비스가 아닙니다.
- 공식 아이템/몬스터/스펠 데이터는 NC 공식 사전으로 연결합니다.
- 사용자 관측값 기반 계산은 공식 내부 공식이 아닙니다.
- 사냥 효율의 kills/hour는 이론상 100% 사냥 지속시간을 가정합니다.
- 강화 계산은 단순 기대비용 모델이며 실제 강화 시스템의 모든 예외 규칙을 자동 반영하지 않습니다.
